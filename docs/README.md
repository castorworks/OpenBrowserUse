## 文档职责

README 只保留项目介绍、入口和快速开始。配置默认值集中在配置参考；部署命令集中在服务部署；公开接口的字段和响应以 OpenAPI 为契约，API 使用说明补充调用流程与语义。内部桌面桥接不属于公开业务 API。

更新功能时同步修改对应使用文档；变更公开接口时同步更新 OpenAPI；变更旧数据或配置行为时更新迁移说明。测试记录不应被写成业务成功率或跨平台验收承诺。
